# Müllkalender

Holt täglich die Abfuhrtermine aus [MyMüll](https://mymuell.de) und stellt sie als abonnierbaren iCal-Kalender bereit.

**Abo-Link:** `https://merathilis.github.io/muellkalender/muell.ics`

Ort und Gebiet werden über die Repository-Variablen `CITY_ID` und `AREA_ID` festgelegt
(IDs aus `https://mymuell.jumomind.com/mmapp/api.php?r=cities` bzw. `...?r=streets&city_id=<CITY_ID>`).
